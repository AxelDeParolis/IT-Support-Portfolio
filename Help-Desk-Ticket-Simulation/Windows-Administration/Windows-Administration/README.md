Windows Administration – Help Desk Simulation

Project Overview

This project simulates common Windows administration and Level 1 IT Support scenarios involving user accounts, account lockouts, software installation, and security permissions.

The objective was to demonstrate structured troubleshooting, security awareness, escalation procedures, and incident documentation.

Note: This is a simulated exercise for learning and portfolio development. No actual Windows administration tasks were performed.

Environment

Operating System: Windows 10/11 (simulated)

Directory Service: Active Directory (simulated)

Support Level: Level 1 Help Desk

Ticket ID: INC-002

User: Sarah Johnson

Department: Human Resources

1. Incident Description

The user reported being unable to log in to Windows because the system indicated that the password was incorrect.

The investigation revealed that the Active Directory account was locked after multiple unsuccessful login attempts.

2. Account Lockout Troubleshooting

The following procedure was selected:

Verify the user's identity.

Investigate the failed login attempts.

Check for possible causes, such as outdated credentials stored on another device.

Unlock the account using the approved company procedure.

Ask the user to test the login.

Key Concepts:

Authentication

Active Directory account management

Account lockout policies

Security procedures

3. Software Installation and Permissions

After successfully logging in, the user reported being unable to install a required application because administrator privileges were needed.

The appropriate response was to:

Verify whether the application was approved by the company.

Confirm the business requirement.

Follow the established software installation procedure.

Escalate the request to the appropriate IT team if administrator privileges were required.

Key Concepts:

User Account Control (UAC)

Administrator privileges

Software approval procedures

Privilege escalation

Principle of Least Privilege

4. Resolution Verification

After the IT team completed the approved installation:

The user was asked to test the application.

The user confirmed that it worked correctly.

The troubleshooting steps and resolution were documented.

The ticket was updated according to company procedures.

5. Ticket Documentation

The simulated incident record included:

Issue: Unable to log in to Windows and install required software.

Root Cause: Active Directory account lockout following unsuccessful login attempts.

Initial Resolution: Account unlocked following identity verification and approved procedures.

Additional Request: Software installation requiring administrator privileges.

Escalation: Application installation handled by the authorized IT team.

Verification: User confirmed successful login and application functionality.

Status: Resolved.

6. Skills Demonstrated

Windows user account troubleshooting

Active Directory fundamentals

Account lockout management

User Account Control (UAC)

Software installation procedures

Administrator permissions

Privilege escalation

Principle of Least Privilege

Incident documentation

User communication

Key Learning Outcome

This exercise demonstrated the importance of following security procedures when managing user accounts and software installations.

It also reinforced the need to verify user identity, investigate account issues, avoid unnecessary administrative privileges, escalate requests appropriately, and document incident resolutions.
